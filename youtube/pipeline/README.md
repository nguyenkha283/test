# pipeline — Quy trình tự động sản xuất video (youtube)

> ⏳ Trống. Code/quy trình sẽ bổ sung sau khi chốt công nghệ.

Dự kiến các bước:
1. Đọc kịch bản từ `content/scripts/approved/`.
2. Tách kịch bản thành các phân cảnh.
3. Sinh giọng đọc cho từng phân cảnh.
4. Ghép hình ảnh/clip + phụ đề + nhạc nền.
5. Render ra `youtube/output/`.
6. Sinh metadata tương ứng vào `youtube/metadata/`.
