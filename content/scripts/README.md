# Kịch bản

Vòng đời: `draft/` → (duyệt) → `approved/` → các kênh sản xuất.

- `template/` — file mẫu, copy ra `draft/` khi viết kịch bản mới.
- `draft/` — đang viết hoặc chờ duyệt.
- `approved/` — đã duyệt, là **đầu vào duy nhất** của pipeline các kênh.

Đặt tên: `<so-thu-tu>-<chu-de-khong-dau>.md` — ví dụ `001-an-toan-khi-o-nha-mot-minh.md`.
