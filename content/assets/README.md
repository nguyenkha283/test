# assets — Tài sản dùng chung

- `images/` — ảnh minh hoạ, hình nền.
- `audio/` — nhạc nền, hiệu ứng âm thanh.
- `fonts/` — font dùng cho video và website.
- `brand/` — logo, bảng màu, intro/outro, thumbnail template.

⚠️ File nặng không commit (xem `.gitignore`). Với tài sản lớn hoặc có bản quyền,
chỉ commit file ghi chú nguồn + giấy phép sử dụng.
