# Quy trình tổng thể

> Khung tài liệu — cần điền chi tiết sau.

## Các bước

1. **Ý tưởng** — chọn chủ đề từ danh sách trong `docs/02-doi-tuong-noi-dung.md`.
2. **Viết kịch bản** — tạo file trong `content/scripts/draft/` theo mẫu
   `content/scripts/template/`.
3. **Duyệt** — kịch bản đạt yêu cầu chuyển sang `content/scripts/approved/`.
4. **Sản xuất theo kênh**
   - Website: biên tập thành bài viết → đăng WordPress (xem `website/`).
   - YouTube: chạy pipeline dựng video (xem `youtube/`).
   - Facebook: chạy pipeline dựng video phiên bản ngắn (xem `facebook/`).
5. **Đăng tải & theo dõi** — ghi lịch trong `content/calendar/`.
